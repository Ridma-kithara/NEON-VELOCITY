These packages, the Unity editor/runtime and URP shaders are governed by Unity's applicable
licence terms and are not relicensed by RK VANTAGE GAMES. A distributed build must comply
with the Unity Terms of Service/Software Licence Agreement and any package-specific terms,

**Built-in font:** the UI resolves `LegacyRuntime.ttf` first, then `Arial.ttf`, through
`Resources.GetBuiltinResource<Font>`. No font file is copied into the repository. The font is
supplied by the Unity runtime; its use is covered by the Unity licence, not by an asset
licence from RK VANTAGE GAMES.

**Built-in primitives and shaders:** world geometry uses Unity's built-in Cube, Sphere,
Capsule, Cylinder and Quad meshes, and materials use URP shaders located at runtime. These
are engine resources, not project-owned art. Textures, sprites, gradients, glow masks and
icons are generated by `TextureFactory.cs`; their original pixel content is project work.

**URP template settings:** `Assets/Settings` and `Assets/InputSystem_Actions.inputactions`
originate from Unity's URP/Input System project templates and have been retained/configured
for this project. They are not third-party marketplace content.

## 6. Generated metadata and reproducibility

- **Meta GUIDs:** `Tools/generate_meta.py` derives a stable GUID from each asset path and
  writes `.meta` files without overwriting existing ones. These GUIDs are project metadata,
  not third-party content.
- **Scene/build wiring:** `ProjectSettings/EditorBuildSettings.asset` references the boot
  scene by its generated GUID; only `Assets/Game/Scenes/Main.unity` is enabled.
- **Audio:** `Tools/generate_audio.py` reproduces the WAV files byte-for-byte from fixed
  seeds and synthesis parameters.
- **Static audit:** `Tools/validate_project.py` checks meta coverage/uniqueness, build-scene
  GUIDs, branding, audio format, missing placeholder markers and required documentation.

Regenerating audio is safe because it is deterministic. Regenerating metas for existing
assets is safe only while asset paths remain unchanged; moving an asset without moving its
meta can break references.

## 7. Redistribution and release checklist

Before publishing a build or store listing:

1. **Confirm Unity licensing.** A licensed Unity seat is required to produce and distribute
   a build. The authoring environment used an active Personal entitlement; any distributor
   or CI runner needs its own compliant Unity licence.
2. **Retain Unity notices.** Include the notices/attributions required by the Unity version
   and packages used; do not present Unity engine code or URP shaders as original work.
3. **Keep branding consistent.** Use **RK VANTAGE GAMES** as the studio and **NEON VELOCITY**
   as the product name; bundle ID `games.rkvantage.neonvelocity`.
4. **Do not extract assets.** Original audio, procedural art, code and documentation are for
   the game, not a standalone asset pack.
5. **Review store terms.** Platform signing, privacy disclosures, content ratings, export
   compliance and store metadata are separate deliverables and are not configured here.
6. **No registration claims.** This project has not registered copyrights or trademarks;
   consult counsel if registration or formal licensing is required.
7. **Preserve provenance.** If audio or generator logic is changed, update the manifest hash
   and this document.
